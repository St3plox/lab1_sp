# ЛР: пункт 1.4, вариант 3 (Qt 6)

`MaskedLineEdit` наследуется от `QLineEdit`. Маска передаётся в конструктор:
`9` — обязательная цифра `0–9`, `a` — обязательная латинская буква `A–Z` или
`a–z`, `-` — неизменяемый знак минуса. Например, маска `999` принимает `000`
и `999`, а `aa-9` принимает `Ab-4`. Неподходящие символы отклоняются.
`isComplete()` сообщает, заполнены ли все позиции, а `value()` возвращает
готовое значение либо пустую строку.

## Установка на Arch Linux

```bash
sudo pacman -Syu --needed base-devel cmake qt6-base
```

Для запуска нужен рабочий графический сеанс X11 или Wayland. Плагины обеих
платформ входят в пакет `qt6-base` в текущем репозитории Arch.

## Сборка и запуск

Из каталога этого проекта:

```bash
cmake -S . -B build
cmake --build build
./build/mask_demo
```

Проверка:

```bash
ctest --test-dir build --output-on-failure
```

В окне представлены три экземпляра класса с разными масками. Попробуйте
ввести `007` в первое поле, `AbC-123` во второе и `12-xy` в третье. Символы
другого типа не вводятся; статус показывает только полностью заполненные поля.
